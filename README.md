# Week 2 – C Programming: Arrays & Functions

This repository contains my Week 2 internship work in C Programming.

The work focuses on arrays, user-defined functions, passing arrays to functions, and a Student Average Calculator mini project.

## Topics Covered

- 1D Arrays
- 2D Arrays
- User-Defined Functions
- Passing Arrays to Functions

## Assignments

### 1. Find Largest Element in Array

A C program that accepts an array of elements and finds the largest element using array traversal.

File: `assignments/01_largest_element.c`

### 2. Count Positive and Negative Numbers

A C program that counts the number of positive and negative elements present in an array.

File: `assignments/02_positive_negative.c`

### 3. Find Factorial Using Function

A C program that calculates the factorial of a number using a user-defined function.

File: `assignments/03_factorial_function.c`

### 4. Add Two Matrices

A C program that accepts two matrices and calculates their sum using 2D arrays.

File: `assignments/04_add_matrices.c`

## Mini Project – Student Average Calculator

A simple C program that calculates the average marks of a student using a user-defined function.

The project demonstrates passing an array of marks to a function.

### Features

- Accepts marks for multiple subjects
- Stores marks using an array
- Calculates the total marks
- Calculates the average
- Uses a user-defined function
- Demonstrates passing an array to a function

File: `mini_project/student_average_calculator.c`
